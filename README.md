# sepsis-hepatocyte-lipid

Analysis code, gene-set definitions and intermediate result tables for:

> **Hepatocyte Lipid Metabolic Reprogramming in Sepsis: A Single-Nucleus RNA-seq Reanalysis**
> Liu M\*, Han W\*, Yu J, Yu Y (corresponding) — *JHEP Reports* (under review)

This repository contains **code and derived tables only**. All primary data are public
(see *Data sources* below) and are not redistributed here.

---

## Data sources

| Layer | Accession | Description | Role in the paper |
|---|---|---|---|
| Discovery | **GSE275689** | Mouse liver snRNA-seq, CLP 24 h. 6 samples; after excluding one mislabelled sample, 3 CLP vs 2 sham; 59,121 hepatocytes (consensus set) | Direction and effect size only (min. attainable permutation *P* = 0.100 at n = 3 vs 2) |
| Parallel | **GSE311736** | FACS-purified hepatocytes, bulk RNA-seq, CLP 8 h, n = 4 vs 4 (VIB-UGent) | All gene-level statistics (DESeq2) |
| Human | **GSE233483** | Human iPSC-derived liver organoids (KuLOs), LPS/IFNγ, n = 2 per stage | Directional evidence only (no *P* values) |

The two mouse layers are **parallel lines of evidence, not discovery–validation**: they differ
in time point (24 h vs 8 h), severity (30% vs 75% ligation) and antibiotic regimen.

## The 12 a-priori lipid programmes

Defined on textbook pathway membership (no data-driven selection), then resolved into
sub-paths: the uptake arm by gene family, the efflux arm by export destination.

| # | Programme | n genes | Note |
|---|---|---|---|
| 1 | FAO | 12 | fatty-acid oxidation |
| 2 | Peroxisome | 11 | peroxisomal β-oxidation |
| 3 | Lipogenesis | 9 | |
| 4 | Cholesterol_synth | 15 | |
| 5 | Lipoprotein_assembly | 9 | |
| 6 | LDLR_clearance | 5 | receptor-mediated LDL/remnant uptake |
| 7 | Scavenger_SR_B | 2 | *Scarb1*, *Cd36* — low resolution, single-gene evidence |
| 8 | FA_transport | 5 | Slc27 family + *Fabp1* |
| 9 | HDL_efflux | 2 | *Abca1*, *Pltp* — effectively *Abca1*-driven |
| 10 | Biliary_excretion | 6 | canalicular transporters |
| 11 | Bile_acid_synth | 3 | *Cyp7a1*, *Cyp8b1*, *Cyp27a1* |
| 12 | Lipid_peroxidation | 10 | |

Run `python3 export_genesets.py` to write `genesets/programs_long.csv`,
`programs_wide.csv` and `programs.gmt`.

**Scoring.** AUCell (recovery-curve cut-off at the top 5% of the ranked gene list,
`max(10, 0.05 × n_genes)`), applied to depth-corrected counts. Because snRNA-seq
captures the nuclear RNA pool, cross-programme comparisons are read as relative
rankings, not absolute pathway activities.

**Deliberate exclusions.** *Abcg1* was dropped from HDL_efflux (hepatocyte detection
rate 2.3%); *Abca1* +3.00 (padj 3.0e-109) is the strongest single-gene signal and
dominates that programme. See the header comment in `scripts/lib_sepsis.py` for the
full list of known uncertainties that are disclosed in the manuscript.

## Reproducing the main results

Raw matrices are **not** in this repository. Download the source matrices from GEO,
place them under `data/raw/`, then run the scripts in numeric order. Principal entry
points and their outputs:

| Step | Script | Output |
|---|---|---|
| Hepatocyte consensus set | `85_hep_set_consensus.py` | `data/proc/hep_set_sensitivity.csv` |
| Depth-corrected programme effects | `58_program_effect_ds1500.py` | `data/proc/fig3_program_effect_ds1500.csv` |
| Permutation test over sample groupings | `58_program_effect_ds1500.py` | `data/proc/fig3_program_perm_ds1500.csv` |
| Independent-cohort DE | `60_validate_bulk.py` | `data/proc/bulk_HEP_CLP_vs_Sham.csv` |
| Programme-level agreement across cohorts | `58_rank_dilution.py` | `data/proc/` |
| Human organoid directionality | `80_human_conservation.py` | `data/proc/human_*.csv` |

## Known limitations carried by this code

These are stated in the manuscript and are repeated here so that the repository is not
read as stronger evidence than the paper claims:

1. **No biological replication in the discovery layer.** n = 3 CLP vs 2 sham; no
   programme reaches significance there. Reporting is direction + effect size.
2. **Sequencing depth is confounded with group** in the snRNA layer; all programme
   values used in the paper are binomial-downsampled to 1,500 UMI. Uncorrected values
   overstate effects.
3. **Cell identity, not counts, controls ambient RNA.** No SoupX/CellBender/DecontX was
   applied; residual hepatocyte-ambient signal would attenuate rather than inflate effects.
4. **Cell–cell communication was not inferred**, because non-hepatocyte self-marker
   detection rates are too low to support it.
5. **Human organoid layer is a technical-replicate series** (one iPSC line) with no
   lobular architecture and no *CYP7A1*, so the bile-acid-synthesis arm cannot be tested there.
6. **Zonation is reported as a negative result** and is not used to support any claim.
